Types of machine learning

- Supervised Machine learning
- Unsupervised machine learning
- Reinforcement machine learning


Supervised machine learning: we use the labeld data. (x,y)
Unsupervised machine learning: we use the unlabeld data. (X)
Reinforcement learning: we train our model with trials.
